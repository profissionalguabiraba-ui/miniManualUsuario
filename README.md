# Base de Conhecimento de Suporte
Toolkit de Help Desk para automação e diagnóstico rápido de problemas comuns no Windows.


## Funcionalidades
Lista situações comuns que um usuário com dificuldades costuma enfrentar em um ambiente de suporte técnico
link com referências oficiais e sites de documentação técnica que apoiam os artigos 
Passo a passo simples para o usuário resolver os problemas mais comuns antes de procurar o suporte

## Tecnologias usadas
- HTML/CSS
- Javascript
- Github Copilot

## Como executar

1. Baixe ou clone o projeto:
```bash
git clone https://github.com/profissionalguabiraba-ui/miniManualUsuario.git
```
2.Abra o arquivo index.html no navegador.
